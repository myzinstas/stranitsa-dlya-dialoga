# Диалог — лендинг для Codex

Это готовый автономный HTML-лендинг кофейни «Диалог».

## Запуск
Откройте `index.html` в браузере. Для локального сервера: `python -m http.server 8000` в папке проекта, затем http://localhost:8000.

## Работа в Codex
Откройте папку `dialog_codex` как проект. Основной файл — `index.html`, стили и изображения встроены.

## Важно
Сохраняйте согласованный дизайн и логотип в шапке и подвале. Меняйте только то, что явно запрошено. Контактные данные и ссылки могут быть демонстрационными.
