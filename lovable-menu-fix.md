# Правка меню для утверждённого сайта «Диалог»

Исходный проект Lovable: https://lovable.dev/projects/3876876e-3853-4a8e-ba3f-aa1407f7b50f

Файл исходного проекта: `src/routes/index.tsx`.

В блоке `К чашке — что-то вкусное` заменить только вторую карточку массива:

```tsx
{ name: "Клаб-сэндвич", photo: sandwich.url, position: "object-center", price: CLUB_SANDWICH_PRICE, category: "sandwiches" as Cat, note: "Цена предварительная" },
```

на:

```tsx
{ name: "Фисташковое пирожное", photo: cheesecake.url, position: "object-[center_70%]", price: 290, category: "desserts" as Cat, note: "Нежный десерт к чашке кофе" },
```

Важно: `cheesecake.url` — существующая фотография чизкейка, **не** фисташкового пирожного. Для точного соответствия нужна новая фотография фисташкового пирожного и её импорт. Цена 290 ₽ здесь примерная, требует подтверждения.

Основное меню с клаб-сэндвичем за 390 ₽, шапку, главный экран, разделы и оба логотипа не менять.

Текущий GitHub-репозиторий содержит автономный HTML-макет, а не полный исходный проект Lovable. Эта запись — подготовленная инструкция по переносу правки, а не утверждение, что действующий сайт уже изменён.
